# FluxSync custom Semgrep rules

Rules generated by `semgrep-rule-creator` skill on 2026-05-23 from seeds in
the diff review (H1) and variant analysis (M2, V1, V2).

## Run

```bash
semgrep --config .semgrep/ crates/
```

## Rules

- `rust.fluxsync.untyped-hash-slice` — fn taking `&[u8]` + returning
  fixed-size array + runtime `if len() < N { return default; }` guard.
  Use `&[u8; N]` instead.
- `rust.fluxsync.unbounded-network-map-insert` — HashMap insert in
  `run_responder` / `transport_recv_loop` / `dispatch_inbound_frame` /
  `handle_driver_cmd` without nearby `len()` cap. Risk: pre-confirm or
  paired-attacker flood.

## Known limitations

- Semgrep Rust does not currently distinguish `pub fn` from `fn`, so
  rule 1 fires on private helpers (still worth fixing).
- Rule 2 cannot reason about preceding `if ... return` early-exit
  guards (only `pattern-not-inside` for wrapper blocks). Expect ~1 FP
  per file with the "check then return then insert" shape.
