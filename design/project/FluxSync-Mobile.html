Home, Devices, Logs, Settings — tous opérationnels. La barre du bas switche entre les écrans. Cette spec est la vérité ; l'APK actuel doit s'aligner dessus.

Pour l'agent Antigravity — checklist d'intégration

  • Bottom navigation rail — 4 onglets : Home, Devices, Logs, Settings. Tous cliquables, tous routés. Indicateur actif = couleur #D43F3F (rouge sénégalais).
  • Home — status hero, master toggle, peer device card, conditions panel (slider battery threshold), recent clipboard (4 derniers items).
  • Devices — liste des peers connus (nom, OS, IP locale, last seen, battery), bouton "Pair new device" → flow QR/code. État empty si 0 peers.
  • Logs — JSON stream rendu en plain English par défaut, toggle "Show raw" pour vue ingénieur. Filtres par level (OK/INFO/WARN/ERR).
  • Settings — sections : General (battery threshold, resume on charge), Security (fingerprint pubkey, rotate keys, unpair all), Network (port, prefer LAN, relay fallback), About (version, build hash, license, "Crafted in Kaolack 🇸🇳").
  • Tokens — fonts Inter Tight + JetBrains Mono, palette dark only sur mobile, accent #D43F3F exclusivement pour critique + brand.
  • Pas de gradient, pas d'emoji décoratif, pas de modal "What's new", pas d'animation gratuite. Densité d'info > bling.
