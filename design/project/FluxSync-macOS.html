● FluxSync v0.5.0-hardened · macOS spec

Menu bar tray + Settings window

Tray dropdown : status + peer + history. Settings window : 4 onglets (General / Devices / Network / About). Cette spec est la vérité — l'app native doit s'aligner.

Pour l'agent Antigravity — checklist d'intégration

  • Tray icon dans la menu bar : SVG monochrome, point vert #3FAE5A quand actif, gris #71717A sinon. Click ouvre le dropdown ci-contre.
  • Tray dropdown 360px : header (logo + version + E2E badge), master toggle avec status label, peer device card avec battery + IP, recent clipboard (5 items), footer "Settings…" + raccourci ⌘⇧V.
  • Settings window 760×500 : sidebar 4 sections + main panel. Onglets : General, Devices, Network, About. Native macOS chrome (traffic lights, blur background si possible).
  • Tokens light theme par défaut sur macOS, font SF Pro ou fallback Inter Tight, mono SF Mono ou JetBrains Mono.
  • Pas de gradient sur l'UI (uniquement wallpaper de fond du desktop). Bordures 1px, radius 4-8px max, ombres très subtiles.
  • Comportement : tray reste ouvert tant que pas click ailleurs. Settings ouvre fenêtre standalone (pas modal sur tray). État partagé entre les deux.
